# Corpus

Captured sessions, one JSONL file per recording. See
[../README.md §9](../README.md) for how they get here and what they are for.

These are **tracked on purpose**. A night of sunrise-lock data cannot be
re-taken — the bedroom, the neighbours' access points and the firmware that
recorded it have all moved on by the next morning. Treat a session file as a
measurement, not as a build artifact.

`synthetic-e2e.jsonl` is the exception: generated by
[../tools/make_smoke_session.py](../tools/make_smoke_session.py), carrying the
`fw_sha` `synthetic`, and present so that a break anywhere in the
capture → ingest → label → replay chain fails on a laptop rather than being
discovered the morning after a wasted night. Regenerate it, never edit it.

`*.replay` files are derived and ignored.
